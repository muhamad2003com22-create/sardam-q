# سیستەمی پێشبڕکێی شەوانەی پەیمانگا (کاتژمێر ١٠:٣٠ شەو)
### (Institute Nightly Elimination Quiz System)

ئەم وێبسایتە بە شێوازێکی پڕۆفیشناڵ و مۆدێرن بە بەکارهێنانی **HTML5, CSS3, JavaScript** دروستکراوە بە تایبەت بۆ بەڕێوەبردنی پێشبڕکێی ڕاستەوخۆی شەوانە بۆ پەیمانگا.

---

## 🌟 تایبەتمەندییە سەرەکییەکان:

1. **یاسای یەک هەڵە = دەرکران (Instant Elimination)**:
   - بەشداربوو بە هەڵەکردنی تەنها یەک پرسیار، ڕاستەوخۆ دەردەکرێت و شاشەی دەرکران بە دەنگی تایبەت و لەرزینی شاشە پیشان دەدرێت.
   - بەپێی یاسا، هەر کەسێک دەرکرا ناتوانێت لە هەمان شەودا دووبارە بەشداری بکاتەوە.

2. **ژمێریاری ڕاستەوخۆ بۆ کاتژمێر ١٠:٣٠ (22:30)**:
   - کاتژمێری دیجیتاڵی خۆکار بە چرکە و خولەک و کاتژمێر دەژمێرێت تا کاتژمێر ١٠:٣٠ی شەو.
   - دوگمەی تایبەتی **"تاقیکردنەوەی خێرا"** دانراوە بۆ ئەوەی بەڕێوەبەر یان تاقیکەرەوە بتوانێت لە هەر کاتێکدا تاقی بکاتەوە بێ ئەوەی چاوەڕێی شەو بکات.

3. **سیستەمی دەنگ (Web Audio API)**:
   - دەنگی سەرکەوتن لە وەڵامی دروست.
   - دەنگی دەرکران و هەڵە.
   - دەنگی تیک-تۆکی چرکەژمێر کاتێک کاتی پرسیار بەرەو تەواوبوون دەچێت.
   - پێویستی بە هیچ فایلی دەنگی دەرەکی نییە و لە ناوخۆی وێبگەڕدا دروست دەبێت.

4. **پەنێڵی تەواوی بەڕێوەبەری پەیمانگا (`admin.html`)**:
   - زیادکردنی پرسیاری نوێ لەگەڵ ٤ هەڵبژاردن و دیاریکردنی وەڵامی دروست.
   - دیاریکردنی کاتی هەر پرسیارێک بە چرکە (بۆ نموونە ١٥ چرکە).
   - سڕینەوە و دەستکاریکردنی پرسیارەکان.
   - بینینی لیستی خوێندکاران و ئەو کەسانەی بە هەڵە دەرکراون لەگەڵ هۆکار و کاتی دەرکرانەکەیان.
   - گۆڕینی کاتی پێشبڕکێ یان ناوی پەیمانگا.
   - پاککردنەوەی پێشبڕکێ (Reset) بۆ دەستپێکردنی شەوێکی نوێ.

5. **شاشەی سەرکەوتن و خەڵات (Victory Screen)**:
   - بۆ ئەو بەشداربووانەی توانیویانە لە هەموو پرسیارەکان بە سەرکەوتوویی دەرباز بن، بە کەرنەڤاڵی کۆنفێتی (Confetti) پیرۆزباییان لێ دەکرێت و ناویان وەک براوە تۆمار دەبێت.

---

## 📁 پێکهاتەی فایلەکان:

- `index.html`: لاپەڕەی سەرەکی خوێندکاران و ڕکابەری کاتژمێر ١٠:٣٠.
- `admin.html`: کۆنترۆڵ پەنێڵی بەڕێوەبەری پەیمانگا بۆ دانانی پرسیارەکان.
- `style.css`: شێواز و دیزاینی تاریک (Dark Midnight Theme)، لەگەڵ پشتیوانی تەواوی زمانی کوردی (RTL).
- `app.js`: لۆجیکی یارییەکە، چرکەژمێر، هەڵسەنگاندنی وەڵامەکان و دەرکردنی بەشداربووان.
- `admin.js`: لۆجیکی بەڕێوەبردن و زیادکردنی پرسیارەکان و پاشەکەوتکردن لە `localStorage`.
- `audio.js`: دروستکەری دەنگەکان بە بەکارهێنانی Web Audio API.

---

تەنها کلیک لەسەر فایلی `index.html` بکە لە کۆمپیوتەرەکەتدا لەڕێگەی وێبگەڕەکەتەوە (Chrome, Edge, Firefox, Safari).
